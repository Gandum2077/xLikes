# xLikes

那些曾经一闪而过但很有价值的内容，不应该只躺在 X 的点赞列表里。
xLikes 会把你点赞的推文同步到本地，变成你的个人知识库。

本项目使用 Node + Web 的运行模式，兼容 [JSBox](https://apps.apple.com/app/id1312014438) 运行。

## 它能做什么

- 同步你自己的 X 点赞列表到本地
- 按 X 风格浏览推文
- 搜索正文、作者、备注和标签
- 随机查看，重新发现以前点过赞的好东西
- 给推文打分、添加标签、写备注
- 归档不喜欢的内容，让主列表保持清爽

[JSBox 一键安装](https://xteko.com/redir?name=xLikes&url=https%3A%2F%2Fgithub.com%2FGandum2077%2FxLikes%2Freleases%2Fdownload%2F1.1.0%2FxLikes.box)

> 需要 JSBox 版本 >= 2.30.1，且购买了 Node.js 运行时功能

### 在 Node.js 上运行

克隆源代码，进入目录并依次执行命令：

```
npm i
npm start
```

默认运行在`http://127.0.0.1:3000`，在`.env`文件中可以设置`HOST`和`PORT`

## 开始使用

首次使用时，应用会引导你完成 X 开发者页面上的准备工作，并填写 OAuth 2.0 Keys。

你需要准备：

- 一个可用的 X 账号
- X Developer Console 中创建好的 Project 和 App
- 已开启的 OAuth 2.0 用户授权
- 至少包含 `tweet.read`、`users.read`、`like.read` 的权限
- 如果希望长期使用自动刷新 Token，授权时还需要包含 `offline.access`

填写凭据后，点击保存并测试。应用会自动识别当前授权用户，不需要手动填写 User ID。

### 同步方式

应用提供两种同步方式：

- 增量同步：自动翻页，遇到连续两条本轮开始前已有的不同推文时停止；本地只有一条推文时，会检查完本页，确认末尾接上它后停止。孤立出现的已有帖子会更新位置并保留本地标记。正常同步无需逐页点击；只有达到每次 10 页的保护上限仍未接上已有记录时，才保存断点并暂停，由你选择是否继续。
- 完全同步：适合第一次建库或需要重新整理全部点赞时使用。由于可能消耗较多额度，开始和从断点继续前都会有确认提示。

每页读取数量可在状态页设置为 5–100。较小的数量适合只检查少量新点赞；增量续传会沿用断点保存的数量和本轮开始前的已有记录。状态页始终提供“增量同步”，用于放弃旧断点、从首页检查最新点赞；旧版增量断点也通过这个按钮从首页安全重查，并自动翻页。有效断点另有“继续增量同步”入口。已有本地推文不会因此删除。

“启动时自动增量同步”也会自动翻页并受每次 10 页的保护上限约束；若存在未完成任务，会等待你手动选择，不会自动续传旧任务。界面会区分达到页数上限、接口限制和分页未推进等暂停原因，暂停不代表已经同步完全部点赞。由于 X API 不提供点赞时间，增量使用已有记录判断接续位置；需要核对全部点赞时可手动选择完全同步。

同步时只保存推文信息。图片和视频会在你浏览到对应推文时再下载。

### 删除或失效的推文会怎样？

如果某条推文已经同步到本地，之后在 X 上删除或变得不可访问，应用不会主动从本地删除它。如果你不想在列表中看到某条推文，可以选择归档。
